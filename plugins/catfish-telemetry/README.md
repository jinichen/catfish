# catfish-plugin-telemetry（匿名遥测客户端）

> **状态**：🟡 P1
>
> **定位**：员工侧的 Hermes 插件，向中央 telemetry 服务上报聚合计数。

---

## 上报什么

- Skill 使用了 N 次（skill 名 + 计数）
- 工具错误 M 次（错误类型 + 计数）
- Token 消耗（已在网关侧记录，插件可做边缘补充）

## 不上报什么

- ❌ 对话内容
- ❌ Skill 内容
- ❌ Tool 参数
- ❌ 员工个人画像

---

## 员工控制

- 默认启用
- `/telemetry off` 可关
- 可查看本地"已上报了什么"
- 上报数据上限（超过阈值自动停）
