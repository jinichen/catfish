## AI Agent 落地路线（6 个 · 按难度分 3 期）

| 期 | Agent | 难度 | 主要瓶颈 |
|---|---|---|---|
| **P1** 0-12 月 | 认证智能体 | 🟢 低 | 无 · 纯文档 |
| **P1** | 招商智能体 | 🟢 低 | 企业库数据 |
| **P2** 12-36 月 | 采购智能体 | 🟢 中 | 价格数据源（稻壳/牡蛎壳无公开 index） |
| **P2** | 客户洞察 | 🟡 中低 | 接 ERP/CRM + 配方知识库 |
| **P2** | 数据要素（技术侧） | 🟡 中 | 数据标准还在建 |
| **P3** 36-60 月 | 生产 Copilot | 🔴 高 | 产线相机 + 缺陷数据集 + PLC 集成 |
| **P3** | 数据要素（交易侧） | 🔴 高 | 数交所挂牌 + 供应链金融生态 |

难度评估基于鲶鱼真实能力 audit（72 工具 / skill 凝固闭环 / MCP 接入 / 多模型路由 / cron / vision）。
详见 `docs/P1-AGENT-实施方案.md`。

**架构缺口**：Agent 02（生产 Copilot）需要**产线边缘节点** — 鲶鱼现在是 desktop agent，跑员工 Mac。
7×24 产线场景 + OT/IT 隔离 + 毫秒级实时性 是架构级新增，不是加 skill 能解决。

## 关键约束（写 PPT / 方案时必守）

1. **不主推鲶鱼** — 这是产业规划，主体是稻生万物。只在讲方案可行性时提"自研 AI 底座"
2. **老规划不引用** — 新规划完全变样，老材料只作背景参考
3. **产业发展高度** — 申报国家基金，突出 AI 对产业升级的价值，不是卖软件
4. **双原料平权** — 稻壳 + 牡蛎壳并列，不只提稻壳（集群 branding 保留"稻壳纤维产业集群"）
5. **不编数据** — 具体规模/投资/KPI 一律"待定"或"与新规划详本同步"
6. **Agent 只出草稿** — 认证申报等合规场景，技术参数与合规声明必须人工签字
