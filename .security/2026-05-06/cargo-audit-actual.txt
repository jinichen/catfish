== 诊断 ==

* unmaintained != vulnerable
  RustSec 给"长期没新版本"的 crate 标 unmaintained. 不是漏洞,
  只是提醒未来若发现 CVE 不会有上游修复. Tauri 上游正在
  迁 GTK3 → GTK4 + 替换 unic-* (urlpattern 上游 PR 已开).

* macOS 不暴露
  GTK 系列 + libappindicator 是 Linux/X11 GUI bindings,
  Tauri macOS target 不编译这些 (只编 webkitgtk-sys 的 stub).

* unsound 两个
  跟 5/6 上午沙箱手动 RustSec advisory-db 比对结果一致.
  glib::VariantStrIter 鲶鱼 Rust 代码无主动调用.
  rand::rng() 鲶鱼用 env_logger 标准 logger, 不在 logger 内调 rand.

== 给客户结论 ==

556 crate, 0 vulnerability, 0 RCE. 19 个 informational warning
全是 unmaintained / unsound 提示, 跟 GTK3 → GTK4 上游迁移有关,
鲶鱼 macOS target 不暴露这些路径.
