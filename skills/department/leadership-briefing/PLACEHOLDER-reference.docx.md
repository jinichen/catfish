# reference.docx 占位

⚠ **本文件是占位** —— 鸿波明天从公司带回真实汇报模板后:

1. 把那份 .docx 文件**复制**到本目录, 重命名为 `reference.docx`
2. 删除本占位 .md 文件
3. 在 SKILL.md 末尾加一段 "## 参考样板" 链接到 reference.docx, 让 LLM 在不确定格式时可以参考

## 为什么需要这个文件

- LLM 写公文不一定生成符合**本公司**风格的细节 (如: 红头格式 / 抄送行格式 / 落款排版)
- python-docx 渲染只能保证**字体 / 字号 / 4 段结构**, 不能保证**风格细节**
- reference.docx 让 LLM 学习真实公司风格, 输出更接近合规

## 拿模板的原则

- **去敏**: 模板里如果有真实人名 / 项目名 / 数字, 鸿波先做脱敏 (把"X 项目" / "Y 主任" 占位)
- **多种**: 拿 3 类模板更好 — 周/月度汇报, 项目立项请示, 重大事项报告. 起码拿 1 类先用
- **完整**: 含红头, 抄送行, 落款, 签批表 (如有) 的完整版本, 让 LLM 看到全貌
