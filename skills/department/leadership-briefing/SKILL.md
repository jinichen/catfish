# leadership-briefing — 公司领导汇报材料 skill

> 严格复刻真实公司公文样式 (鸿波 2026-04-29 提供 PDF 样板).

---

## 何时触发

员工说出以下意图时**必须**用这个 skill:

- "写一份给 XX 领导的汇报材料" / "写一份给 X 总的汇报"
- "生成 X 月工作汇报 / 项目进度汇报 / 部门季度汇报"
- "写一份关于 X 的请示件 / 决策事项 / 立项请示 / 重大事项报告"
- "给公司 / 集团 / 总部上报 X"
- "写一份呈批件 / 请示件 / 报送材料"

## 文档结构: blocks 模式

5 段标题**固定**, 每段内部用 blocks 数组组织内容.

### 段标题 (固定 5 个, 顺序不可调)

```
一、背景与现状
二、问题与影响
三、方案
四、请示事项
五、下一步计划
```

### Block 类型 (4 种)

#### `paragraph` — 普通段落

```python
{"type": "paragraph", "text": "公司持证人员 5 人, 尚缺 1 人. 详见附件 1."}
```

- 自动首行缩进 2 字符
- 红字高亮根据 `important_phrases` 自动应用

#### `kv_table` — 项目-内容两列表 (公文方案标志)

```python
{"type": "kv_table", "rows": [
    ["用人部门", "已与人力部、集成能力中心沟通确认 ..."],
    ["公司归属", "先入职北福, 后转中电"],
    ["待遇标准", [   # 多行内容用 list 包
        "1. 月工资: ...",
        "2. 五险一金: ...",
    ]],
]}
```

- 左列固定窄 (3cm), 右列宽 (13cm)
- 内容支持单行 (str) 或多行 (list[str])
- **公文 § 三方案 必用这个**

#### `table` — 普通多列表 (问题清单 / 数据汇总)

```python
{"type": "table",
 "headers": ["序号", "问题", "影响", "紧迫度"],
 "rows": [
     [1, "数据更新滞后 3 个月", "已错失 2 个投标窗口", "高"],
     [2, "审核流程跨 4 部门", "单条 11 工作日", "中"],
 ]}
```

- 表头加粗
- 列宽自动均分
- 用于 § 二问题 / 数据汇总等场景

#### `ordered_list` — 数字层级列表 (下一步计划专用)

```python
{"type": "ordered_list", "items": [
    {"text": "启动一级建造师招聘工作:", "subs": [
        "(1) 需符合社会招聘条件 (学历本科及以上; 年龄低于 40 岁)",
        "(2) 招聘过程中重点关注相关专业背景及一级建造师执业资格;",
    ]},
    {"text": "人员到岗并完成资质人员配备后, 同步推进法人变更.", "subs": []},
    {"text": "后续管理:", "subs": ["集成能力中心负责入职人员的考勤与工时管理."]},
]}
```

- 顶级 `1.` `2.` `3.` 阿拉伯数字
- 子项 `(1)` `(2)` 中文括号
- 子项左缩进 2 字符
- **公文 § 五下一步 必用这个**

### 段内灵活混排

每段的 `blocks` 数组可以**任意组合**任意 block 类型:

```python
{"heading": "二、问题与影响", "blocks": [
    {"type": "paragraph", "text": "该缺口已对业务产生影响:"},
    {"type": "table",        # 多个问题用表格列出
     "headers": ["问题", "影响"],
     "rows": [["数据滞后", "错失投标"]]},
    {"type": "paragraph", "text": "若直接变更法人, 将 ..."},
]}
```

## 附件 (CSV 清单)

### 何时用附件

- 主文档正文里有**长清单 / 数据明细** (例: 145 类资质 / 50 名持证人员 / 30 项预算条目)
- 直接放正文会让文档**冗长难读**, 领导抓不到重点
- 解决: 正文写一句"目前 X 详见附件 N", 附件用 CSV 提供完整数据

### 附件结构

```python
attachments=[
  {
    "filename": "附件1-资质人员清单",   # 不带扩展名, skill 自动加 .csv
    "kind": "csv",
    "headers": ["序号", "姓名", "证书编号", "专业", "持证日期", "状态"],
    "rows": [
      [1, "张三", "粤01-123456", "机电工程", "2020-05-12", "在岗"],
      [2, "李四", "粤01-234567", "建筑工程", "2019-08-20", "在岗"],
      ...
    ],
  },
  {
    "filename": "附件2-补位方案预算明细",
    "kind": "csv",
    "headers": ["费用类别", "金额 (元/年)", "说明"],
    "rows": [
      ["员工工资", 32400, "税后 2000/月 × 12 + 月薪"],
      ["五险一金 (公司)", 11385, "由公司统一缴纳"],
      ["合计", 43785, ""],
    ],
  },
]
```

### 附件细节

- **命名**: `附件1-XXX.csv` / `附件2-YYY.csv`, 跟正文里 "详见附件 1" 编号对得上
- **位置**: 跟主 .docx **同目录**, 员工 Finder 一打开看全部
- **编码**: UTF-8 BOM, Excel/Numbers/记事本 / WPS 直接打开中文不乱码
- **数字**: rows 里数字直接传 int / float, 不加引号

## 输出路径规则

```python
# 员工指定路径 (推荐场景: "保存到 ~/Desktop/")
output_path="~/Desktop/补位汇报.docx"
# → 主文件在 ~/Desktop/补位汇报.docx
# → 附件在 ~/Desktop/附件1-资质人员清单.csv 等 (同目录)

# 没指定 → 默认到鲶鱼托管目录
output_path=None  # 或不传
# → 主文件在 ~/.catfish/output/2026-04-29/14:30:25_补位汇报/补位汇报.docx
# → 附件在同目录
```

**为啥不用 /tmp**: macOS 重启清空 + 系统 7 天后自动清理, 客户机演示完文件就没了, **demo 翻车风险大**. 员工想清理用 Companion 仪表盘里"清理 30 天前输出"按钮 (TODO).

## 红字高亮

```python
important_phrases=[
    "尚缺 1 人",
    "公司归属",
    "先入职北福, 后转中电",
    "不享受企业年金",
]
```

- 这些短语在文档**任何位置**出现 (正文 / 表格 / 列表) 都自动标红
- 长短语优先匹配 (避免短的截断长的)
- 不重叠

## 错别字 + 合规自审

LLM 生成内容时**必须**自审:

1. **错别字高危**: 的/得/地 / 即/既 / 那/哪 / 已/以 / 帐/账 / 部署/布置
2. **称谓**: "公司" 不写 "公司方" / "我公司" 写 "本公司" / "领导" 不写 "上级"
3. **数字**: 千分位空格不用逗号, 金额大写"元 / 万元" 不混用
4. **不要出现**: emoji / 英文标点 (用 ， 。 ： 不用 ,.: ) / 半角空格混排
