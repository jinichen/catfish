# weekly-report — 员工周报 skill

> 部门内日常周报, 不是给公司领导的正式汇报 (那个走 leadership-briefing).

---

## 何时触发

员工说出以下任一意图:

- "写一份本周周报"
- "整理这周工作"
- "本周总结"
- "周报材料"
- "周报 + 日期" (例: "写一份 4 月 24 日的周报")

---

## 输出格式

完全复刻你们公司 .xlsx 模板:

| 序号 | 项目-事项名称 | 本周进度 | 下周计划 | 计划完成时间 | 备注 |
|------|---------------|----------|----------|--------------|------|
| 1 | 合规管理 | 6 到位 AI 预判平台的代码、规则优化 | 按需求是否需要继续优化 | | |
| 2 | 资质 | 1. xxx 现场审核准备\n2. 27000 审核准备\n3. 和金智达沟通 | 持续中 | | |
| 3 | 安全日常工作 | 部门日常安全检查工作 | 持续中 | | |
| 4 | 其它 | ... | ... | | |

- **多行内容**: "本周进度" 字段允许 `\n` 分行 (员工写 "1. xxx 2. yyy" 自动换行显示)
- **空字段**: "计划完成时间" / "备注" 可空, 不强制填
- **表头底纹**: D9E7F5 (浅蓝)
- **列宽自适应**: 序号窄 (5), 项目 (15), 本周/下周 (40), 计划完成时间 (15), 备注 (20)

## 数据采集流程

### ⭐ 方式 A+ — 自动从历史抽取 (Phase 2 简化版, **优先尝试**, 鸿波 4-30 加)

员工说"写本周周报" / "写周报" / "本周做了什么" 时, 你**优先**:

1. 调 `session_search` 工具 (hermes 自带), 搜本周内 (最近 7 天) 的 user message
   - 例: `session_search(query="本周", time_range="7d")` 或 `session_search(time_range="7d")` 取所有近 7 天 sessions
2. 看注入的 **catfish 跨 session 上下文** (`## 📅 员工最近 7 天 session 历史` + `## 📝 员工长期日记`) 找到本周 session 摘要
3. 综合两者抽取员工本周做的事, 按合规 / 资质 / 安全 / 项目 / 其它分类初稿
4. 把初稿给员工 review (例: "我看到你本周做了 X / Y / Z, 是否补充?")
5. 员工确认 / 补充后, 调 `catfish_run_skill(skill_path='department/weekly-report', params={...})` 真生成 .xlsx

**好处**: 员工不需要手动列举所有事项, 鲶鱼"知道"员工做了啥.
**底线**: 员工**必须 review** 你的抽取 — 不要直接生成, 错过的事让员工补.

例:

```
员工: 写一份本周周报

鲶鱼: 我从你最近 7 天的对话历史看到, 本周主要做了:
  - 合规: 拟资质汇报材料, 4 段框架协商
  - 资质: ISO27001 现场审核, 一级建造师补位 (秦树鹏注册), 27000 准备
  - 安全: 部门日常安全检查
  - 其它: ?
是否补充? 下周计划是什么?

员工: 加"中电 / 北福高新申报材料准备", 下周计划: 27000 审核 / CSMM 审核预备 / 上会材料

鲶鱼: [调 catfish_run_skill] → 生成 .xlsx
```

### 方式 A — 员工主动列举 (备用, 鲶鱼没历史可参考时用)

```
员工: 写一份本周周报
鲶鱼: 你本周做了哪些事? 按类别列, 每条一行 (类别可以是: 合规 / 资质 / 安全 / 项目 / 其它):

员工: 
合规: AI 预判平台代码 + 规则优化, 下周看需求是否继续
资质: 业务连续性五星 + ISO27040 现场审核准备, 27000 审核准备, 跟金智达沟通
安全: 部门日常安全检查
其它: 团建组织, 周三

鲶鱼: [调 catfish_run_skill weekly-report] → 生成 .xlsx → 出 FilePill
```

### 方式 B — 上周 .xlsx 滚动 (适合长期员工, 大部分事项是延续的)

```
员工: 把上周周报作为基础, 调整一下生成本周的
[拖一份上周 .xlsx 进来]
鲶鱼: [读取上周内容] [反问哪些条目要保留 / 哪些是新增] → 生成本周
```

### 方式 C — 自动从 hermes 历史抽取 (TODO Phase 2)

接 hermes audit log + 鲶鱼会话历史, 模型自动判断本周做了哪些 tool 调用 / 完成了哪些任务, 拼成周报草稿. 员工 review 后微调即可.

## 数据形态契约

| 字段 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| `employee_name` | str | 是 | 员工姓名, 进文件名 |
| `week_label` | str | 是 | 本周描述 (例 "2026年4月20日-2026年4月24日"), 进 Sheet 标题 |
| `items` | list[dict] | 是 | 至少 1 条; 每条含下面 5 字段 |
| `items[].category` | str | 是 | 项目/事项名称 (例: 合规管理) |
| `items[].this_week` | str | 是 | 本周进度 (允许多行 \n) |
| `items[].next_week` | str | 否 | 下周计划 (默认 "持续中") |
| `items[].deadline` | str | 否 | 计划完成时间 (默认空) |
| `items[].note` | str | 否 | 备注 (默认空) |
| `output_path` | str | 否 | None → 自动 `~/Desktop/周报-<员工>-<YYYYMMDD>.xlsx` |

---

## 错别字 + 合规自审

- 类别简短 (2-6 字), 一致用"X 管理 / X 工作 / 项目 X" 等
- 本周进度具体 (有数字 / 名词), 不要写"开展了 ... 工作"这种空话
- 下周计划要么具体, 要么写 "持续中" / "暂无", 不要留空 (除非确实没有下周计划)
- 错别字高危: 的/得/地 / 项/相 / 已/以

## 跟 leadership-briefing 的区别

| 项 | weekly-report | leadership-briefing |
|---|---|---|
| 输出格式 | .xlsx (单 Sheet 表) | .docx (5 段公文) + CSV 附件 |
| 受众 | 部门内 / 直接领导 | 公司 / 集团领导 |
| 频率 | 每周 1 份 | 不定期, 重要事项触发 |
| 长度 | 4-8 行表 | 3-5 页 |
| 是否合规字体 | 否 (默认字体即可) | 是 (方正小标宋 + 仿宋_GB2312) |
| 是否签批 | 否 | 是 (有"请示事项") |
