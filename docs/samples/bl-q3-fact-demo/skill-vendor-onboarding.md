# 新供应商入库 skill (v2.0)

> **本 skill 已于 2026-Q1 按集团合规升级**, 资质清单包含 ISO 9001 + ISO 27001
> + 反贿赂承诺书 + 财务审计报告. 与各版本采购流程修订兼容.

## 触发场景

员工说"新供应商" / "供应商入库" / "增加 vendor" 等关键词时, 调这个 skill.

## 工作流

1. **收集供应商基础资料** — 问员工:
   - 供应商全称 + 营业执照号
   - 联系人 + 邮箱 + 电话
   - 主营品类
   - **是否涉数据接入** (用于决定 ISO 27001 是强制还是建议)

2. **资质审查完整清单** — 走法务/合规预审, 要求供应商提供:
   - 营业执照副本
   - **ISO 9001 质量管理体系证书** (硬性)
   - **ISO 27001 信息安全管理体系证书** (涉数据接入强制, 其他建议)
   - 近三年财务报告 (审计版)
   - 法人身份证 + 签字授权书
   - **反贿赂合规承诺书** (本年起新增, 标准模板见 OA)

3. **提交内部 OA**:
   - 调 catfish_browser_navigate 打开 https://oa.company.com/vendor/new
   - 填表 + 上传上述材料
   - 提交后获取审核单号

4. **通知合规审核**:
   - 调 catfish_send_message → 合规专员 (默认 compliance@company.com)
   - 邮件标题: "新供应商入库申请 - <供应商名> - <单号>"
   - 抄送: 申请人 + 部门经理 + (涉数据接入时) CISO

5. **审核状态跟踪**:
   - 1 周后自动调 catfish_browser_check_status 查审核进度
   - 通过 → 通知员工 vendor 已建档可下单
   - 退回 → 转告员工补充材料原因

## 错误处理

- 供应商已存在数据库 → 直接返已有 vendor_id, 不重复创建
- 资质材料缺项 → 列出缺什么, 让员工先收齐再调
- ISO 27001 缺失 + 涉数据接入 → 严格不允许过审, 必须先取证
- 邮件发送失败 → 退到 catfish_browser_navigate 让员工手动通知

## 注意

- 严格按集团最新合规要求执行 (2026 年起加强信息安全资质)
- 不要替供应商填资料 — 必须供应商方提供原件扫描
- 法务审核期间不要催, 一般 1-2 周
