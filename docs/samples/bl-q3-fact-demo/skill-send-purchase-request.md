# 采购请求 skill (v1.0)

## 触发场景

员工说"我要买 XX" / "采购 YY" / "申请购买" 等关键词时, 调这个 skill.

## 工作流

1. **确认基本信息** — 问员工:
   - 采购物品名称 + 型号
   - 数量 + 单价
   - 用途 (项目名 / 部门常备 / 临时需求)
   - 期望到货日期 (用于判断"急采购"标记)

2. **金额判断**:
   - 单笔金额 < 50,000 元: 走部门内部审批流, 部门经理签字即可
   - 单笔金额 ≥ 50,000 元: 必须走部门总监审批流, 系统自动加 "总监审批" 节点
   - 单笔金额 ≥ 100,000 元: 走 CFO 审批 (集团硬规)

3. **填请求单** (调 catfish_browser_navigate 打开内部 OA):
   - URL: https://oa.company.com/purchase/new
   - 填表字段: 品名 / 型号 / 数量 / 单价 / 用途 / 期望到货日期 / 申请人

4. **提交 + 通知**:
   - 提交后获取请求单号
   - 用 catfish_send_message 通知部门审批人 (邮件 / 飞书)

## 错误处理

- 员工没给齐信息: 不要自动填默认值, 必须**问完所有 4 项**再提交
- 金额跨阈值时: 显示警告"金额超过 5 万元, 进入总监审批流, 预计 3-5 工作日"
- 急采购: 用户明确说"急" / "今天就要"时, 标 "rush" 字段, 但**不需要额外签字** (走标准流即可)

## 注意

- 严格按 v3.1 版财务流程: 5 万以下快速通道, 5 万以上总监.
- 不要替员工编造采购理由 — 用途字段必须员工自己填.
