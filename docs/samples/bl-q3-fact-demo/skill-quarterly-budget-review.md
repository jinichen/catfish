# 季度采购预算复盘 skill (v1.0)

## 触发场景

部门经理说"季度预算" / "下季度采购计划" / "提交采购规划" 等关键词时, 调这个 skill.

## 工作流

1. **拉本季度采购数据** (调 catfish_execute_code):
   ```python
   # 从内部 ERP / 财务系统拉本部门本季所有 PO
   purchases = db.query("SELECT ... FROM purchase_orders WHERE dept=? AND quarter=?", ...)
   ```

2. **生成下季度预算预测**:
   - 按品类分组: 办公耗材 / 设备 / 软件订阅 / 外包服务
   - 跟历史 3 季度趋势对比, 给出建议金额 (±10% 区间)
   - 标记"新增大额项"需要单独说明

3. **整理成 Excel 表**:
   - sheet 1: 摘要 (本季实际 + 下季预测对比)
   - sheet 2: 明细 (按品类)
   - sheet 3: 大额项说明

4. **报送时间提醒**:
   - 默认: 财务部要求季度采购计划**提前 2 周**报送
   - 即下季度首月 1 号前 14 天必须报送
   - 如逾期会被锁预算

5. **生成报送邮件**:
   - 收件人: 财务部预算经理 (默认 yu.budget@company.com)
   - 抄送: 部门总监
   - 附件: 上面生成的 Excel
   - 正文模板: "尊敬的预算经理, 现报送 X 部门 YY 季度采购计划 ..."

## 错误处理

- 拉数据失败 → 用 catfish_browser_navigate 提示员工手动从 ERP 导出 CSV
- 数据极少 (< 5 条) → 警告"本季采购数据不足, 预测可能不准, 建议人工评审"
- 超期未报 → 严重警告, 建议立即报送 + 同时邮件解释

## 注意

- 严格按公司财务部门要求: 提前 **2 周**.
- 不要在邮件正文里附整个 Excel 内容, 太大. 用附件即可.
