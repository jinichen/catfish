## 真**根因** — 没 "model role" 抽象层

代码混 2 个**不同** concerns:
1. **业务意图**: "这是主力 chat" / "这是快速评级" / "这是 vision 多模态"
2. **物理 model name**: catfish-private-main / catfish-public-qwen-flash

现在两件**混在一起**, code 真用 string `catfish-private-main` 同时表达"主力意图 + 物理 name". 客户 rename = **业务意图错绑物理 name**.

## 真**方案 A** — role abstraction (源头治本)

### 真新概念: role

代码**只引用 role**, 不引用 model name:

```rust
// email_scheduler.rs (改后)
let model = role_resolver::resolve(Role::RateFast);
```

```python
# multimodal_guard.py (改后)
vision_model = role_resolver.resolve(Role.VISION)
```

### 真新 yaml: `roles.yaml` (中央配置)

```yaml
# central/llm-gateway/config/roles.yaml
# 真**单一**真**业务意图 → 物理 model name** 映射. 客户改这一文件就**全代码**跟着走.

roles:
  # 主力 chat — Companion 真 picker 默认
  chat_default: catfish-private-main

  # 快速评级 / 钓鱼扫描 / 政治审查 — background task 真省钱模型
  # 默认安全选 private; 客户嫌慢可指 public flash 显式接受数据出端
  rate_fast: catfish-private-main

  # 长 context 总结 (跨 session journal / catfish-memory dream)
  summarize: catfish-public-gemini-pro

  # 多模态 — 含图请求 multimodal_guard 真切这个
  vision: catfish-private-vision

  # embedding — wiki / advisor 语义搜索
  embedding: catfish-private-embed

  # advisor 真 single-shot 工具调用 (强 tool_use)
  advisor_call2: catfish-public-deepseek-flash  # /beta 严格 tool_choice 支持

  # proactive starter / a2a aux — 内部用例真**自动 fallback** 链
  fallback_chain:
    - chat_default        # 引用别的 role, 真递归 resolve
    - rate_fast
    - public_flash

  # 备用真**公网 flash** (rename-safe alias 给 fallback 用)
  public_flash: catfish-public-qwen-flash

# RBAC default allowed (alembic migration 真用 role + resolve 时生成 model list)
rbac_default_allowed:
  employee: [chat_default]
  manager: [chat_default, vision, summarize]
  admin: [chat_default, vision, summarize, public_flash]
  sysadmin: [chat_default, vision, summarize, public_flash, advisor_call2]
```

## 真**风险 / nuance**

1. **循环引用**: `fallback_chain` 真**递归 resolve** role refs, 要防 A → B → A 死循环 (DFS 真带 visited set)
2. **runtime 拉 API**: companion-app / hermes 启动时 gateway 没起 → 真**cache fallback** 用本机 `~/.catfish/roles.cache.yaml` (上次拉到的)
3. **picker 联动 (P3.5.28)**: 真**优先级** picker file > role.chat_default. 员工选啥真**override** role default
4. **历史 RBAC DB row**: 老员工 rbac_allowed_models 真**存的是 model name**, 不是 role. migrate 时**保留**字符串 (假设是 role name or model name 真**resolve 时**容错)
5. **rename 死 chain**: 客户改 `chat_default: customer-a-main` 但**没改 fallback_chain** 真**引用 stale role name** — schema validation 真**启动 hard fail** (好过 silent)
6. **embedding role**: companion-app embedding.rs 真**直接调** /v1/embeddings, 不走 chat. role.embedding 真传 model name 给 embedding endpoint
