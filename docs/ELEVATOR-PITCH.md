# 鲶鱼 30 秒电梯演讲 · 5 个版本

> 不同对象 (CTO / 部门领导 / 员工 / CISO / 财务) 你 30 秒内说什么.
> 背熟. 客户问"你们鲶鱼是干嘛的", 看对方角色直接套. 不要每次重新组装.

---

## V1 · 给 CTO / 技术决策者

**30 秒**:

> 鲶鱼是企业级**LLM 中台 + 员工副手**. 三层架构: Companion 在员工本机, tool-bridge 隔离工具调用, 中央 gateway 做 LLM 路由 + 审计 + 容灾.
>
> 跟 ChatGPT 不一样的核心是: 数据**全本地** (对话不出员工电脑), LLM **跨厂商任意切** (你们自己 qwen / 公网 gemini / 容灾 fallback), 中央**只看 metadata** (token / latency / 安全事件), 看不到内容.
>
> 12 个月内 ship Phase 3 Catfish Federation — 跨员工 agent 协作. 这是 SaaS 永远做不到的 (它们是中心化), 也是同质化产品没设计的护城河.
>
> 私有化部署, 你们 IT 全审代码.

**触发场景**: 客户 CTO 问"你们技术架构什么样" / "怎么保证企业级"

---

## V2 · 给部门领导 / 业务负责人

**30 秒**:

> 你们部门员工 8 小时, 4 小时在切系统 / 找数据 / 套模板 / 写汇报. 这 4 小时鲶鱼能帮他们干掉.
>
> 演示场景: 员工说"抓 EIS 资质 145 条, 套部门模板生成本月汇报", 鲶鱼**全程自动**做完, 员工只 review 最后的 .docx 改两个字按发送.
>
> 不是替代员工. 是把员工**从重复劳动里解放**, 去做需要思考的事.
>
> 50 人部门一年装下来, 每人省 10 小时 / 周 = 部门一年省 25000 小时. 部门效率上 30% 不夸张.
>
> 私有化部署, 你们数据不出公司. 一次性 license, 不抽 token 流水.

**触发场景**: 部门领导问"它能给我员工带来什么" / "对我的 KPI 有什么用"

---

## V3 · 给员工 / 实际使用者

**30 秒**:

> 你早上 9 点开电脑要登 4 个系统对吧? 报销跨 3 个表填 12 个字段对吧? 周报凑字数翻一周邮件半小时对吧?
>
> 鲶鱼帮你干掉这些. 你跟它说"帮我登 EIS 抓今天数据, 套部门模板写汇报", 它**自动**做完, 你审一下按发送.
>
> 关键: 它不偷你密码 (走 Keychain), 不传你对话给厂商 (全本地), 不替你做决定 (草稿 / 发送 / 提交都你本人按).
>
> 装上 30 分钟学一下, 一周后你不会想关掉它. 真的.

**触发场景**: 给员工演示 / 入职培训 / 推广

---

## V4 · 给 CISO / 数据安全负责人

**30 秒**:

> 鲶鱼**不是后补合规**, 设计阶段就是合规.
>
> 三层数据保护:
> 1. **边缘**: 对话内容 + memory + 工具历史**全在员工本机** `~/.catfish/`, 永远不出员工电脑
> 2. **凭据**: secret_ref + macOS Keychain, 密码**永远不进 LLM 上下文**, 我们 prompt regex 检测员工不小心发明文密码会自动 audit 标记
> 3. **审计**: 中央 gateway 写 JSONL audit, 字段是 user / model / token 数 / TTFT, **没有对话内容字段** — 代码层面写死的, 你们 IT 可以审计代码
>
> 离线模式 + token 短 TTL + 强制 SSO. 客户 IT 拿到全套 audit 工具, ~600 行 SSO 代码可读可审.
>
> 你们 CISO 部门提的合规要求, 我们能正面回答, 不是"我们正在规划".

**触发场景**: CISO 问"数据安全怎么保证" / "员工密码怎么处理" / "审计能追溯吗"

## V5 · 给财务 / 预算决策者

**30 秒**:

> 鲶鱼是**资本支出 (一次性) + 维护费**, 不是 SaaS 月费 / 按 token 付.
>
> 50 人部门: 一次性 X 万 license + 年度 15-20% 维护. 5 年总成本约 X*1.8 万.
>
> 不收的: API token 流水 (员工怎么用都不收钱, 你们用自己 LLM) / 中央云费 (你们机房) / 升级费 (年度维护包含).
>
> ROI: 50 人部门, 每人每周省 10 小时, 一年部门省 25000 小时, 按内部时薪折算约 X*30 万 /年.
>
> 投资回收期: 2-4 个月. 5 年累计 ROI 30 倍以上.
>
> 关键: 我们靠**装得久 + 推广到其他部门**赚钱, 不靠卡员工 token. 商业模式跟 SaaS 反着来 — 你们用得越多, ROI 越高, 我们续约越稳.

**触发场景**: 财务问"成本结构" / "ROI 怎么算" / "为什么不用 SaaS"

## 30 秒计时练习

每个版本对着镜头 / 录音练 5 遍, 计时**必须 ≤ 30 秒**. 30 秒内说不完 = 没准备好, 客户会没耐心听.

理想节奏: **3 句话**, 每句 10 秒, 一句一个 take-home message.

V1 给 CTO 的拆解:
- 句 1 (10s): 鲶鱼是 LLM 中台 + 员工副手, 三层架构
- 句 2 (10s): 数据全本地, LLM 跨厂商, metadata 可审
- 句 3 (10s): Phase 3 Federation 是护城河, 私有化全审

每句精炼到这个程度, 30 秒不超.
