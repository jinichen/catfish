## §1 发布链路 (Phase 2 + Phase 3 UI)

### §1.1 第一次 share — 触发警告 + 自配敏感词

- [ ] 选某 wiki 文件 (e.g. `wiki/entities/老李.md`) 含手机号 `13800138000`
- [ ] 点 "📤 分享到部门" → dialog 弹, 顶部黄底强警告 (manifesto 公理 4)
- [ ] 头部蓝底 hint "💡 想扫客户名/项目代号? 创建模板", 点 "创建模板"
- [ ] 看到绿色 "✓ 已创建模板: /Users/.../wiki/sensitive_terms.txt", 文件真存在
- [ ] dialog 显示 "分享到: dept/<你的部门>" (账号没设部门时显红字, 确认按钮灰), 勾 "我知道已 pull 副本撤不回"
- [ ] 点 "确认分享" → 红底警告显 "扫到 1 类内容警告 — pii (1 处)"
- [ ] 点 "我看过了, 强发" → 绿底 "✓ 已分享到 dept/<你的部门>"
- [ ] 改一下这条 wiki 再分享一次 → 绿底 "✓ 已更新 dept/<你的部门> 里的这一条", hub 上还是一条不是两条
- [ ] dialog 顶部 "关闭" 关掉

### §1.2 校验 hub 真有这条

```bash
# 走 gateway (用员工 token)
TOKEN=$(cat ~/.catfish/oauth/id_token)
curl -H "Authorization: Bearer $TOKEN" http://127.0.0.1:8999/v1/wiki/documents | jq
```

- [ ] 返 `{documents: [{namespace: "dept/finance", title: "老李", ...}], count: 1}`
- [ ] body_md 含老李原文本 + `{{phone_1}}` (auto_scrub 没生效, 因为 wiki 不自动 scrub, 但 ack=true 让原文进 hub)

> 注: wiki 跟 skill 不同, 是**原文直接进 hub**, 不脱敏. 风险已经用强警告 + ack 让员工知情.

### §1.3 校验本机敏感词扫到

编辑 `~/.catfish/wiki/sensitive_terms.txt` 加一行 `FFCS`. 选一条含 "FFCS" 的 wiki, share 时:

- [ ] warnings 含 `sensitive_terms` category 命中 "FFCS"

## §3 撤回链路 (manifesto 公理 4 核心)

### §3.1 原 publisher 撤回

LLM 调 `catfish_wiki_unpublish({hub_namespace: "dept/finance", hub_file_id: "<刚才的 id>"})`. 或直接 curl:

```bash
TOKEN=$(cat ~/.catfish/oauth/id_token)
curl -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"reason":"客户翻脸了"}' \
  "http://127.0.0.1:8999/v1/wiki/documents/dept/$(python3 -c 'import urllib.parse;print(urllib.parse.quote("研发部"))')/<file_id>/unpublish"
```

- [ ] 返 `{ok:true, summary:"已撤回...", manifesto_note:"..."}`
- [ ] PG 查 row 仍存在 (audit 保留), `stale_after_unpublish=true`, `body_md=''`, `unpublished_reason='客户翻脸了'`
- [ ] FS `~/.catfish-hub/wiki/dept/<部门>/<file_id>.md` 删掉, `<file_id>.meta.json` 还在且 `stale_after_unpublish: true`

### §3.2 员工 B 视角看 stale

- [ ] Dashboard WikiHubCard 60s refresh 后:
  - 头部红 badge "⚠ 1 你装的已撤回"
  - 那条 row 红框显 "⚠ 原作者已撤回. 你本机仍有副本, 自己决定是否卸. (manifesto 公理 4 — 中央不强制清你本机)"
  - 不显安装 button (本来已装, 也不能再装)

### §3.3 WikiPreview 黄底 stale banner

- [ ] 切到知识体系 tab → 选刚才装的部门 wiki ("老李 · finance")
- [ ] 正文上方黄底 banner: "⚠ 原作者已撤回这条 wiki (2026-06-10)" + 公理 4 解释 + reason 行 "原作者撤回原因: 客户翻脸了"
- [ ] 本机文件内容仍能看 (没被清, 公理 4)

### §3.4 员工 B 自决: 卸载本机副本

- [ ] 点 "🗑 卸载本机副本" → "🗑 确认卸载" → 卸载

- [ ] 本机文件 mv 到 `~/.catfish/wiki-shared/.trash/<ts>-wiki-shared_dept_finance_<file_id>.md` + sidecar
