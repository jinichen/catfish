# 5 月客户交流 · PPT 大纲

> 30 张内. 鸿波导入 Keynote / 飞书文档时按这个填. 每张备注 (notes) 含演讲口语稿.

**总时长目标**: 30-40 分钟 (15 分钟核心演示 + 5 分钟 Roadmap + 10-20 分钟 Q&A)

**听众假设**: 客户 IT 负责人 / 部门领导 / CTO / 数字化负责人 (1-3 人)

**演示原则**:
- 别讲"AI 概念", 讲**员工日常痛点** + **鲶鱼怎么解决**
- 每张 ≤ 20 字标题, 每段 ≤ 3 行
- 30% 时间演示 live demo (录屏 fallback), 70% 讲架构 / 商业 / Roadmap

### Slide 8 · Live Demo (60s)

**演示步骤**:
1. 员工屏幕显示一封客户邮件 (问报价)
2. 跟小鲶说"看下屏幕, 帮我处理这封"
3. catfish_screenshot → multimodal_guard 自动 route 到 vision 模型
4. 模型: "客户问报价 X 产品. 历史记录他上次买过 Y, 推荐报价 1.2 万. 起草回邮?"
5. 员工说"起草", 模型用 docx skill 写邮件草稿
6. **关键**: 不替员工按发送. 员工本人按发送键

**关键字幕**:
- vision 模型自动切, 不需要员工手动选模型
- 草稿 / 决策都员工 review, 鲶鱼不替员工拍板
- 隐私设计原则: 员工是用户不是被监控对象

|---|---|---|

| audit | (你看不到) | **📊 中央 metadata 可审** |

**口语稿**: "你们 CISO / 数据安全部门最关心的事, 我们设计阶段就解决了. 不是后补的合规."

### Slide 17 · 锁层差 3 · ★ Catfish Federation (Phase 3)

```
员工 A 的鲶鱼  ←─→  员工 B 的鲶鱼  (隐私边界严格)

例:
A: "问下张三老板对项目 X 的看法"
   ↓
A 鲶鱼 → B 鲶鱼 → B 公开偏好答复
   ↓
A 拿到答复, 不打扰张三

部门 1 个员工教鲶鱼新流程
   ↓
全部门 50 人鲶鱼自动学会
   ↓
部门集体智慧自动沉淀
```

**口语稿**: "**这是真正护城河**. SaaS 永远做不到 (它们是中心化的, 改不出来). 同质化产品没设计这层 (它们是工具不是基础设施). 12 个月内 ship."

### Slide 18 · 总结差异化

```
我们差异化 ≠ "比 ChatGPT 强". 差异化在:
1. 私有化部署 + 数据完全本地
2. 跨厂商 LLM 路由 + 中央可审 metadata
3. Phase 3 跨员工 agent 协作 (Federation)
```

## 准备 PPT 时的纪律

- ✅ 字号 ≥ 24pt, 标题 ≥ 36pt (会议室投影别让客户眯眼)
- ✅ 每张 ≤ 20 字标题, 段落 ≤ 3 行
- ✅ 颜色: 主色 catfish-cyan (#4eb3d3), 警告橙, 危险红. 不超 4 色
- ✅ 不用 emoji 装饰 (国央企风格), 但 🐟 标识自己保留
- ✅ 不要 "我们的优势是..." 这种空话, 用 "你们 IT 拿到 X 控制点" 这种具体
- ✅ 数字尽量精确 (例: "175 行 SSO 代码 客户可审", 不是 "代码量小")
- ❌ 不要露 hermes / skill_manage 等内部术语 (BRAND-VOICE.md 红线)
- ❌ 不要在 PPT 写"AI" "智能体" "大语言模型" 等词太多 (听腻了, 没差异化)
