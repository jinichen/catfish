鸿波 11/18 看了 LearnHarness (github.com/amosblomqvist/learnharness, AGPL-3.0, 1 万星), 问「学习能力的方案?」。
本文: 借它的教学方法和运行机制, 结合鲶鱼已有的知识库本体、会议、语音、题库, 做成员工能天天用的学习功能。

> 许可: LearnHarness 是 AGPL —— 照搬它的代码 / 提示词原文进鲶鱼, 发给客户时鲶鱼也得按 AGPL 开源。
> 所以**借方法和结构, 用 Python / 中文自己写**, 不复制代码和提示词原文。

## 2. 教学方法 (借 LearnHarness, 改成适合公司场景)

一次学习 = 一个「学习」会话, 四个阶段, 每个阶段一个角色 (各自的提示词 + 能用的工具):

1. **摸底**: 先问清目标 (「答辩时能讲清应急处理流程」比「了解 CCRC」具体), 再对每个要用到的知识点
   **二分法找边界**: 从目标附近的难度开问, 答对且有把握 → 大步往上, 答错 → 往下收。每题带
   「我不知道」「有几成把握」「你怎么想的 (可以语音说)」。结束时交一份评估: 每个知识点稳拿的、卡住的、误解。
2. **排路线**: 从评估出发画一张「先懂 A 才能懂 B」的路线图 (节点 = 知识点, 边 = 前置)。已经会的不重讲,
   跟目标无关的不讲。员工看过点「开始」才讲; 讲的过程中发现缺基础, 小鲶自己改路线图。
3. **讲解**: 每次只往前走一步, 一步一个循环 —— 先让你**猜** (不要求答对) → 讲 → **检查** (要能用学过的推出来,
   不是复述原话; 选择题每个错误选项对应一种具体的误解, 选了哪个就知道你哪里想岔了) → 答错就先补, 不往上盖。
   讲的内容一律来自查到的资料 (知识库 / 文件 / 邮件 / 官网), 每段注明出处。
4. **练习**: 另开的练习, 题目不点名考哪条 (逼你自己想起来); 不同知识点**换着练**, 不连着考同一条;
   难度卡在八成左右答对; 卡住时提示一级一级给 (只给最少的一步); 每题记结果、用了几级提示、错在哪类
   (想不起来 / 分不清 / 算错 / 粗心 / 结构没懂)。

讲完和练完的东西进**复习** (第 5 节), 早安简报提醒今天要复习几条。

不照搬的: LearnHarness 面向「彻底弄懂数学物理」, 讲解很长; 公司场景多是「记准规定 + 讲得出来」,
默认讲解短、检查多, 员工可以选「快速」(跳过猜、少讲多考) 或「深入」。

## 3. 知识沉淀: 在本体上加一层「要点 + 推理」

LearnHarness 把讲过的内容拆成**结论**和**推理链** (A + B 推出 C), 每条记出处, 下次直接接着用。
鲶鱼的本体记的是「东西」(证书、人、部门) 和它们的关系 / 属性; 学习要的是「道理」(规定、条件、流程为什么这样)。
两层挂在一起, 不另起一套:

- **要点** `{id, 说法, 别名, 出处[知识库条目 / 文件 / 邮件 / 会议纪要 / 网页], 挂在哪条知识上 (wiki rel_path)}`
- **推理链** `{前提[要点 id], 结论 要点 id, 出处}`; 只有真的「推得出」才算, 「有关」不算。
- 存 `~/.catfish/learning/graph.db` (SQLite, 不用 JSON 文件追加 —— LearnHarness 自己承认 JSON 没有事务是弱点)。

**怎么建** (照它的三步):
1. 抽: 讲解每攒够约 4000 字 / 导入一份资料时, 让模型交「要点 + 推理链」, 格式不对退回重交 (最多 4 次);
   字段被模型写成字符串的先修 (`"[...]"` → 数组) 再校验。
2. 认同一条: 先用关键词检索给每条新要点找 5 个候选旧要点, 再让模型判「是不是同一个意思」, 是就并成一条
   (别名 + 出处合并)。这一步全局排队, 一次只跑一个, 防止重复。
3. 合并: 代码做, 不用模型 —— 去重、A→C 已经成立就删掉 A+B→C。

**用在哪**: 摸底先读「他以前学过哪些要点」不重复考; 练习从选中的要点和推理链出题; 问小鲶时也能引用推理链
(「为什么二级要求三个项目」→ 前提是哪几条规定)。删一份资料时, 别的资料也支持的要点留着, 只摘掉这份的出处。

## 4. 运行方式 (借它的运行机制, 按鲶鱼现有架构)

**跑在 tool-bridge, 不跑在 hermes 主对话里。** 学习是长流程、要强结构 (阶段、路线图、题目状态), 跟会议一样
由 Companion 调 tool-bridge `learn/*` 接口, 模型经网关调用。每一步是**一次结构化输出** (出一道题 / 讲一段 + 检查 /
改路线图 / 结束摸底), 不放开给模型自由调工具 —— 跟纪要、改纪要一个路子, 稳、好测。

借的几条规矩:
- **先存后算**: 员工的回答先写进会话记录再调模型; 调模型失败, 回答不丢, 可以「重试」。
- **一个会话同时只跑一步**: 第二个请求直接拒 (界面显示「小鲶还在想」)。
- **题目卡住这一轮**: 出了题这一轮就结束, 等员工答完才往下走; 题目和标准答案在员工看到之前就存好
  (答完不许模型改答案)。
- **切走不丢** (跟 1.2.210 改纪要同一套): 打了一半的回答、正在生成的讲解, 切 tab / 重开都在。
- **后台活儿**: 查资料、出示意图放后台跑, 跑完写进会话再接着讲; 并发数有上限 (照它的做法按「每次模型请求」限流)。
- **长会话压缩**: 超过上下文预算时, 前面的部分压成固定几节的摘要 (员工掌握情况 / 讲到哪 / 路线图原样 / 当前在干嘛),
  原文留在磁盘上。

数据都在本机 `~/.catfish/learning/` (会话记录、路线图、要点图、复习状态); 只有挑出来的资料片段和对话经网关给模型。

## 5. 复习: 升级现有题库

现有 `practice.py` (题库 + 错题 SM-2) 保留, 改三处:
- 调度换成 **FSRS** (Anki 新版同款, Python 有 MIT 许可的 `fsrs` 包; 现有复习记录 `review_events` 可以回放迁移)。
- 一条要点出**几张卡**, 每张对应一个「什么时候需要想起它」的场景 (不是同一句话换个问法);
  卡片挂在要点上, 一条要点一份复习进度。
- 来源扩到: 学习会话讲过的要点、会议纪要的决议 / 规定 (会后问一句「要不要记住这几条」)、导入的资料。
早安简报的「今天要复习 N 道」照用, 点进去在「学习」页里复习 (不再塞进对话框)。

## 6. 语音: 答辩陪练和外语

- **答辩陪练**: 小鲶扮评审老师, 用语音提问 (语音合成), 员工口头回答, 本机转写 (高精度组件 Qwen3-ASR,
  口头回答一般一两分钟, 转一遍十几秒), 再按评分点逐条对照: 讲到了哪几点、漏了什么、哪里说得不对 (带资料出处),
  然后追问。漏的点进复习。
- **外语**:
  - 跟读: 小鲶读一句 → 员工跟读 → 识别后跟原句逐词对照, 标出识别不出来的词 (说明: 这是「听不清 / 读错的词」,
    不是口音打分, 本机没有可靠的发音评分模型)。
  - 情景对话: 小鲶扮客户 / 面试官 / 同事, 语音来回; 结束后按练习的规矩复盘 (哪个表达想不起来、哪两个词混了),
    生成复习卡。
  - 语法 / 用法讲解走第 2 节的教学流程 (有道理可讲的部分), 固定搭配 / 词汇走复习卡。
- 语音合成用哪个: 先用 Edge 晓晓 (宣传片在用, 中英文都好, 但要联网、文字会发给微软); 要求不出本机的单位,
  换本机合成模型做成可选组件 (跟高精度转写组件一样的方式)。

## 7. 界面

Companion 加一个「学习」页 (左边栏, 会议下面):
- 首页: 进行中的学习、今天要复习几条、我学过的要点 (按知识库条目分组, 能展开看推理链)。
- 新建学习: 一句话说目标 + 可选「从知识库 / 文件 / 会议带资料」+ 模式 (快速 / 深入 / 答辩陪练 / 外语)。
- 学习中: 左边对话 (讲解、题卡: 选项 + 我不知道 + 把握 + 想法, 想法可语音), 右边路线图 (当前在哪、走过哪)。
  选中一段讲解可以「边上问」(小窗, 不打断主线, 问过的下一步主线会看到)。
- 练习 / 复习: 一题一卡, 提示按钮一级一级给, 结束显示这次练了什么、哪类错多。
主对话里说「帮我准备 CCRC 答辩」也能直接开一个学习会话 (跳到学习页)。

## 8. 分几步做

| 步 | 内容 | 验收 |
|---|---|---|
| 1 | 学习会话骨架: `learn/*` 接口、会话存储 (先存后算、单步锁、切走不丢)、摸底 + 路线图 + 讲解 + 检查; 「学习」页 | CCRC 应急处理: 摸底 ≤ 8 题找到边界, 路线图员工认可, 讲 3 步每步有检查; 讲解每段有出处 |
| 2 | 练习 (换着练、提示阶梯、错因分类) + 复习换 FSRS、一条要点多张卡; 早安提醒点进学习页 | 练 10 题不连考同一条; 旧错题迁移不丢 |
| 3 | 要点 + 推理链: 抽 / 认同一条 / 合并, 挂到知识库条目; 导入资料、会议纪要进来 | 同一规定从两份资料来只留一条, 出处两份; 删一份资料另一份的要点还在 |
| 4 | 答辩陪练 (语音问答 + 按评分点对照) | ITSS 二级 10 道常见问题全程语音走完, 漏点进复习 |
| 5 | 外语 (跟读对照、情景对话、复习卡); 本机语音合成可选组件 | 英语情景对话 10 轮, 复盘出卡; 不联网时能用本机合成 |

每一步按惯例: 测试全过、界面在真实窗口尺寸下看过、升版本、推送打包 (Mac 两个 + Windows)。
