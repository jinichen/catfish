# 鲶鱼 Catfish · Gateway 模型清单编辑指南

**版本**: v0.18.0 (2026-07-16)
**目标读者**: 达华 IT / 中央服务运维人员
**适用场景**: 加自定义模型 / 换 fallback 链 / 关掉某个公网模型 / 调超时/上下文窗

---

## 前言 · 什么时候要改 models.yaml

`~/catfish/central/llm-gateway/config/models.yaml` 定义了 gateway 能路由到哪些模型. 出现下面**任何一种**需求就改这个文件:

- **加达华定制模型** (自己训的 daodian-qwen / 部门专属模型)
- **换内网端点** (不是内网 IP:port 变了, 而是想加**新 provider**, e.g. GLM / Kimi / 星火)
- **删公网模型** (数据敏感行业禁止走公网, 只留内网)
- **改 fallback 链** (默认 chain 里剔除 gemini, 或加你自己的备用)
- **调超时 / 上下文** (Qwen3.6 max context 从 128K 提到 256K, 或 timeout 从 300s 缩到 180s)

**不需要**改 yaml 的场景 (只改 `.env` 即可):
- 换内网 qwen URL → 改 `INTERNAL_LLM_BASE_QWEN_MAIN` 即可
- 换 API key → 改 `INTERNAL_LLM_KEY` / `DASHSCOPE_API_KEY` 等
- 换 postgres 密码 → 改 `PG_PASSWORD`

---

## 挂载机制 · 为啥不用 rebuild docker image

`docker-compose.yml` 里 gateway 段已经把 config 目录**挂载为 volume**:

```yaml
gateway:
  volumes:
    - ./llm-gateway/config:/app/config:ro    # ← host 端改, container 内立刻看到
```

意思是: 你在 host 上 `vim ~/catfish/central/llm-gateway/config/models.yaml`, container 内部 `/app/config/models.yaml` 就是同一个文件.

**因此**: 改文件 **不用 rebuild image**, 只需 `docker compose restart gateway` (10 秒), 新 config 生效.

## 编辑 · 3 步流程

### 1. Backup + Edit

```bash
cd ~/catfish/central/llm-gateway/config

# 先 backup, 万一改坏能回滚
cp models.yaml models.yaml.bak-$(date +%Y%m%d-%H%M%S)

# 编辑
vim models.yaml
```

### 2. 语法 verify (改前别 restart, 先测 yaml 语法)

```bash
python3 -c "import yaml; yaml.safe_load(open('models.yaml'))" && echo "OK yaml 合法"
```

**输出 `OK yaml 合法`** 才继续, 否则 vim 回去修.

### 3. Restart gateway + verify

```bash
cd ~/catfish/central
docker compose restart gateway

# 等 15 秒 gateway 完全起来
sleep 15

# verify healthy
docker compose ps gateway
# STATUS 列应该是 "healthy" 或 "Up (healthy)"

# 看 log · 应该看到 "loaded N models" 类似字样
docker compose logs gateway --tail 30 | grep -iE "model|loaded|catalog"
```

**若挂了** (STATUS Restarting) → 回滚:

```bash
cp models.yaml.bak-<time>  models.yaml
docker compose restart gateway
```

## 完整字段参考 (ModelConfig schema)

每个模型条目结构 (只有 `name`, `display_name`, `upstream` 是**必填**, 其余有 default):

```yaml
- name: xxx                              # 必填 · 唯一 · 不能包含空格
  tier: private                          # 可选 · private | public · 默认 private
  display_name: "员工看到的中文名"        # 必填
  mode: chat                             # 可选 · chat | embedding · 默认 chat
  default: false                         # 可选 · 是否默认模型 (只能有 1 个 default: true)

  upstream:                              # 必填 · nested
    model: openai/qwen_v3_5_122b_a10b   # 必填 · LiteLLM 完整名 (provider/model_id)
    api_base: ${INTERNAL_LLM_BASE_QWEN_MAIN}  # 可选 · self-hosted 必填
    api_key_env: INTERNAL_LLM_KEY        # 可选 · 默认 INTERNAL_LLM_KEY
    timeout: 300                         # 可选 · 单位秒 · 默认 60
    param_overrides:                     # 可选 · gateway 强制覆盖客户端传的参数
      temperature: 0.7
      thinking:
        type: disabled

  context_window: 128000                 # 可选 · 员工承诺的上下文窗 · 默认无
  max_output_tokens: 65536               # 可选 · 单次 output 上限 · 默认 = context_window
  supports_tool_use: true                # 可选 · function calling · 默认 false
  supports_streaming: true               # 可选 · 默认 true
  supports_vision: true                  # 可选 · 多模态 · 默认 false
  recommended_for:                       # 可选 · picker 智能推荐用 · 默认 []
    - general
    - chat
    - tool_use
    - vision
    - code
  cost_tier: free                        # 可选 · free | paid · 默认 free

  fallback:                              # 可选 · 上游挂时自动切链
    on_errors:                           # 触发 fallback 的错误
      - 429
      - 502
      - 503
      - 504
      - "timeout"
      - "connection error"
      - "rate limit"
    chain:                               # 按顺序尝试的 model name
      - catfish-public-qwen-flash
      - catfish-public-deepseek-flash
    max_hops: 2                          # 最多切几次 (防循环)

  rate_limits:                           # 可选 · 上游限速 preflight (防 413 暴 stack)
    tpm: 8000                            # tokens per minute
    rpm: 30                              # requests per minute
    tier: "groq-free"                    # 上游 tier 标识 (给员工友好提示)
```

### `recommended_for` 常见 tag

- `general` · 通用
- `chat` · 聊天
- `tool_use` · 需要工具调用
- `code` · 代码任务
- `vision` / `ocr` / `image_analysis` · 多模态
- `fast` · 低延迟
- `summarizer` · 跨 session 总结 (BL-E13 内部用例)
- `proactive_starter` · 主动闲聊起话题
- `a2a_aux` · A2A federation 辅助任务
- `fallback` · 兜底备份

### `upstream.model` provider 前缀

必须带 provider 前缀 (LiteLLM 规范):

| provider | 用法 | 示例 |
|---|---|---|
| `openai/` | OpenAI 或 **OpenAI-compatible 自托管** (含所有内网 qwen 平台) | `openai/qwen-72b` |
| `deepseek/` | Deepseek 官方 API | `deepseek/deepseek-v4-flash` |
| `gemini/` | Google Gemini | `gemini/gemini-2.5-pro` |
| `anthropic/` | Anthropic Claude | `anthropic/claude-3-5-sonnet-20241022` |
| `groq/` | Groq | `groq/llama-3.3-70b-versatile` |

## 环境变量插值 (`${VAR}` / `${VAR:-default}`)

yaml 字符串值里可以写 `${VAR}` 或 `${VAR:-fallback}`, 加载时从 `.env` (host 端) 或 docker-compose 传的 env 替换.

**用途**: 敏感信息 (URL / key / UUID) **不进 yaml**, 只在 `.env`. 员工/git repo 看不到.

**例子**:

```yaml
# yaml 里:
api_base: ${INTERNAL_LLM_BASE_QWEN_MAIN}

# .env 里:
INTERNAL_LLM_BASE_QWEN_MAIN=http://10.0.5.20:9998/v1
```

gateway 启动读 `.env` 后自动替换. **改完 .env 也要 restart gateway 才生效**.

**带 default 语法**:

```yaml
api_base: ${DAODIAN_QWEN_BASE:-http://127.0.0.1:9998/v1}
# .env 里没 DAODIAN_QWEN_BASE → 用 127.0.0.1:9998
# .env 里有 → 用 .env 里的值
```

## 场景 1 · 加达华定制模型

**假设**: 达华内网有一台 GPU 服务器 `10.0.5.30:9999`, 跑了自训的 daodian-qwen-r1-72b 模型, OpenAI-compatible API.

### Step A · 在 `.env` 加 URL + key

```bash
vim ~/catfish/central/.env

# 加两行:
DAODIAN_QWEN_BASE=http://10.0.5.30:9999/v1
DAODIAN_QWEN_KEY=sk-daodian-xxxxxxxxxxxxxxxx
```

### Step B · 在 `models.yaml` 加条目

**位置**: 找到 `models:` 段的最后一个 `- name:` 条目, 在它下面追加 (缩进对齐):

```yaml
  # ---------- 达华内部 · Daodian R1 72B ----------
  - name: daodian-qwen-r1-72b
    tier: private
    display_name: "达华定制 · Daodian Qwen R1 72B"
    mode: chat

    upstream:
      model: openai/daodian-qwen-r1-72b
      api_base: ${DAODIAN_QWEN_BASE}
      api_key_env: DAODIAN_QWEN_KEY
      timeout: 240

    context_window: 128000
    supports_tool_use: true
    supports_streaming: true
    supports_vision: false
    recommended_for: [general, chat, tool_use, code]
    cost_tier: free

    fallback:
      on_errors: [429, 502, 503, 504, "timeout"]
      chain: [catfish-private-main]        # 挂了切鲶鱼默认内网
      max_hops: 2
```

### Step C · verify + restart

```bash
python3 -c "import yaml; yaml.safe_load(open('~/catfish/central/llm-gateway/config/models.yaml'))"
cd ~/catfish/central
docker compose restart gateway
sleep 15
docker compose logs gateway --tail 30 | grep -i "daodian"
```

**期望 log** 里能看到 `loaded model: daodian-qwen-r1-72b` 之类. 员工 Companion 里 chat picker 也能选到 "达华定制 · Daodian Qwen R1 72B".

## 场景 2 · 关掉 Gemini (数据不出海)

**背景**: 数据敏感行业要求所有 LLM 请求**不到境外**, Gemini 得禁掉.

### 做法 · 2 步

**Step A · 从 fallback chain 里删 gemini 条目**

`vim models.yaml`, 搜 `gemini-flash` / `gemini-pro`, 从**所有** `chain: [...]` 里删掉:

```yaml
# 改前:
fallback:
  chain: [catfish-public-qwen-flash, catfish-public-deepseek-flash, catfish-public-gemini-flash]
                                                                     ^^^^^^^^^^^^^^^^^^^^^^^^^^^ 删

# 改后:
fallback:
  chain: [catfish-public-qwen-flash, catfish-public-deepseek-flash]
```

**Step B · 让 gemini 模型不在 catalog 出现**

最简单: `.env` 里 `GEMINI_API_KEY=` **留空**. Gateway 启动时检测到 key 缺 → 自动把 catfish-public-gemini-* 从 catalog 隐藏, 员工 picker 里根本看不到 gemini.

**Or** · 更彻底: `vim models.yaml` 把 `catfish-public-gemini-pro` 和 `catfish-public-gemini-flash` 两个条目**注释掉** (每行前加 `#`) 或**删除**.

### verify

```bash
docker compose restart gateway
sleep 15
# 员工 Companion chat picker 应该看不到任何 gemini 相关 (Companion 前端拉 /v1/catalog)
curl -H "Authorization: Bearer $CATFISH_ADMIN_TOKEN" \
     http://localhost:8999/v1/catalog | jq '.data[] | select(.id | contains("gemini"))'
# 应该输出空
```

## 场景 3 · 只用内网 (完全离网)

**背景**: 政企内网, 服务器所在机房**完全不出外网**, 所有公网模型都必须禁用.

### 做法 · 3 步

**Step A** · `.env` 里 3 个公网 key **全留空**:

```bash
DASHSCOPE_API_KEY=
DEEPSEEK_API_KEY=
GEMINI_API_KEY=
```

**Step B** · `vim models.yaml`, 从**所有** private 模型的 fallback chain 里, 只留 private:

```yaml
# 改前:
fallback:
  on_errors: [429, 502, 503, 504, "timeout", ...]
  chain: [catfish-public-qwen-flash, catfish-public-deepseek-flash, catfish-public-gemini-flash]
  max_hops: 2

# 改后 (option 1 · 只切内网视觉/多模态):
fallback:
  chain: [catfish-private-vision]
  max_hops: 1

# 或 (option 2 · 直接删 fallback 段, 上游挂就 502 给员工):
# (删掉整个 fallback: 段)
```

**Step C** · verify + restart:

```bash
docker compose restart gateway
sleep 15

# verify · 公网模型不在 catalog
curl http://localhost:8999/v1/catalog | jq '.data[] | select(.tier=="public")'
# 应该输出空
```

## 场景 4 · 改内网 qwen timeout (推理慢)

**背景**: 达华内网 qwen 平台推理**特别慢** (M4 大模型 + 5 万字 context 撞 300s), 想调到 600s 兜个稳.

```yaml
# 找 catfish-private-main:
upstream:
  timeout: 300   # ← 改这行
                 # 改成 600
```

**注意**: gateway 里也有 keepalive / worker timeout, 若 timeout > 900 (uvicorn 默认), 上层挂. 保守值 **≤ 600**.

## 常见踩坑 + 排查

### 坑 1 · `fallback chain refers to unknown model: xxx`

**gateway 启动 log**:
```
WARN: fallback chain refers to unknown model: catfish-public-qwen-flash
```

**原因**: chain 里写的 model name 拼错了, 或者 model 被删了但 chain 里还引用.

**修**: `grep -n "catfish-public-qwen-flash" models.yaml`, 看哪个 chain 引用了不存在的 model, 改掉.

### 坑 2 · `env variable INTERNAL_LLM_KEY is not set`

**gateway 日志**:
```
RuntimeError: env variable INTERNAL_LLM_KEY is not set -- cannot call model 'openai/xxx'
```

**原因**: `.env` 里没配这个 key, 但 models.yaml 里 `api_key_env: INTERNAL_LLM_KEY` 引用了.

**修**: `vim ~/catfish/central/.env`, 加 `INTERNAL_LLM_KEY=sk-xxxxx`, `docker compose restart gateway`.

### 坑 3 · yaml 缩进错

**gateway 启动 log**:
```
yaml.scanner.ScannerError: mapping values are not allowed in this context
```

**原因**: yaml 对缩进敏感, `- name:` 必须缩进 **2 空格** (跟 `models:` 的元素对齐), 其字段缩进 **4 空格**.

**修**: 打开 `models.yaml` 参考已有条目缩进结构, 或用 `python3 -c "import yaml; print(yaml.safe_load(open('models.yaml')))"` 交互定位错误行.

### 坑 4 · 改完 restart 后 gateway 不断 Restarting

```bash
docker compose ps gateway
# STATUS 一直 Restarting (× N)
```

**排查**:

```bash
docker compose logs gateway --tail 50
# 看最后 20-30 行, 找具体 Exception
```

若是**yaml 语法**问题 → 回滚 backup:
```bash
cd ~/catfish/central/llm-gateway/config
cp models.yaml.bak-<latest-time>  models.yaml
docker compose restart gateway
```

若是**pydantic validation**问题 (字段类型错) → 对照本文档"完整字段参考" 表格验证, 改回合法值.

若是**model 名重复** → 每个 `name` 必须唯一. `grep -c "^  - name:" models.yaml` 数一下.

### 坑 5 · 员工 picker 里看不到新加的模型

**check 1** · gateway catalog API:
```bash
curl http://localhost:8999/v1/catalog | jq '.data[] | .id'
# 应该看到新 model name
```

**check 2** · api_key 是否配了 · 若 `api_key_env` 指向的 env var **不存在或为空**, gateway 自动把这个 model 从 catalog **隐藏** (`is_available` 属性判断).

**修** · vim `.env` 加对应 API key, restart gateway.

## 附录 A · models.yaml 完整字段表

| 字段 | 必填 | 类型 | 默认 | 说明 |
|---|---|---|---|---|
| `name` | ✅ | str | — | 唯一 · 员工看不到 · 用来 fallback chain 引用 |
| `tier` | ⭕ | str | `private` | `private` (内网) / `public` (公网) |
| `display_name` | ✅ | str | — | 员工 chat picker 里看到的中文名 |
| `mode` | ⭕ | str | `chat` | `chat` / `embedding` |
| `default` | ⭕ | bool | `false` | 是否新员工默认模型 (只能 1 个 true) |
| `upstream.model` | ✅ | str | — | LiteLLM 完整名, e.g. `openai/qwen-72b` |
| `upstream.api_base` | ⭕ | str | 无 | 自托管 endpoint URL, 支持 `${ENV}` |
| `upstream.api_key_env` | ⭕ | str | `INTERNAL_LLM_KEY` | env 变量名, 不是 key 本身 |
| `upstream.timeout` | ⭕ | int | `60` | 单位秒 |
| `upstream.param_overrides` | ⭕ | dict | `{}` | gateway 强制覆盖客户端参数 |
| `context_window` | ⭕ | int | 无 | 员工承诺的上下文窗 |
| `max_output_tokens` | ⭕ | int | = context_window | 单次 output 上限 |
| `supports_tool_use` | ⭕ | bool | `false` | function calling |
| `supports_streaming` | ⭕ | bool | `true` | SSE stream |
| `supports_vision` | ⭕ | bool | `false` | 多模态 |
| `recommended_for` | ⭕ | list[str] | `[]` | picker 智能推荐 tag |
| `cost_tier` | ⭕ | str | `free` | `free` / `paid` |
| `fallback.on_errors` | ⭕ | list | `[429, 503, 504, "timeout"]` | 触发切链的错误 |
| `fallback.chain` | ⭕ | list[str] | `[]` | 按序尝试的 model name |
| `fallback.max_hops` | ⭕ | int | `2` | 防循环 |
| `rate_limits.tpm` | ⭕ | int | 无 | tokens per minute · Groq preflight 用 |
| `rate_limits.rpm` | ⭕ | int | 无 | requests per minute |

⭕ = 可选  ✅ = 必填
