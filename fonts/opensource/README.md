## 怎么加字体到这里

1. 确认字体许可证允许商用 + 分发 (SIL OFL / Apache 2.0 / GPL 都行)
2. 把 .ttf / .otf 文件放到本目录
3. 用 `git add -f opensource/<filename>` 强加 (因为 .gitignore 默认 ignore 字体二进制, 防止误 commit 商业字体)
4. **更新本表**: 字体名 / 文件名 / 大小 / 替代什么 / 许可证 / 来源 URL
5. 把许可证文件 (LICENSE.txt 之类) 也一起放到 `opensource/<font-name>/LICENSE.txt`
6. PR 审核, 通过即合并

---

## 不允许放这里的字体

- ❌ 方正字库系列 (方正小标宋 / 方正书宋 / 方正黑体 等)
- ❌ 中易中标 (仿宋_GB2312 / 楷体_GB2312)
- ❌ 汉仪字库
- ❌ 文鼎字库 (除明确开源版本)
- ❌ 任何**用户机自带 / 操作系统附赠**的字体 (微软 / 苹果有他们自己的授权链, 我们别掺合)

如果客户需要这些, 走 [`customer/`](../customer/) 目录, 客户用自己的授权.
